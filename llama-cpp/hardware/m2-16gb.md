# MacBook Air M2 16GB

## Recommended Models
- Qwen3.6-35B-A3B UD-IQ2_XXS (~10.8 GB) or UD-Q2_M (~11.5 GB)

## Full Command

```sh
llama-server -hf unsloth/Qwen3.6-35B-A3B-GGUF:UD-IQ2_XXS --offline --port 8080 -ngl 99 -fa 1 --cache-type-k q8_0 --cache-type-v q8_0 -b 512 -ub 512 -c 16384 --jinja
```

## Parameters
- `-c 16384` — safe context on 16GB
- `-b 512 -ub 512` — small batch to avoid swapping
- `--cache-type-k/v q8_0` — small context keeps memory use low
