# MacBook Pro M4 Max 48GB

## Recommended Models
- Qwen3.6-35B-A3B UD-Q6_K_XL (~31.8 GB) or UD-Q5_K_XL (~26.6 GB)
- Qwen3.6-27B UD-Q6_K_XL

## Full Command

```sh
llama-server -hf unsloth/Qwen3.6-35B-A3B-GGUF:UD-Q6_K_XL --offline --port 8080 -ngl 99 -fa 1 --cache-type-k q8_0 --cache-type-v q8_0 -b 2048 -ub 2048 -c 131072 --jinja
```

## Parameters
- `-c 131072` — 128k context
- `-b 2048 -ub 2048` — large batch size
- `--cache-type-k/v q8_0` — high-precision KV cache
