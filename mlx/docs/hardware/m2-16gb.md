# MacBook Air M2 16GB

Latency-first settings for one interactive coding or tool-using agent with `mlx-community/Qwen3-4B-Instruct-2507-4bit`.

## Hardware

- `Mac14,2`
- base M2: 8-core CPU and 10-core GPU
- 16 GiB unified memory
- 100 GB/s memory bandwidth
- approximately 11.8 GiB MLX recommended working set

## Recommended Command

```sh
mlx_lm.server \
  --model mlx-community/Qwen3-4B-Instruct-2507-4bit \
  --host 127.0.0.1 \
  --port 8080 \
  --max-tokens 8192 \
  --prompt-cache-size 2 \
  --prompt-cache-bytes 3000000000 \
  --decode-concurrency 1 \
  --prompt-concurrency 1 \
  --prefill-step-size 1024
```

Launcher equivalent:

```sh
run-mlx-server --m2-16gb --model mlx-community/Qwen3-4B-Instruct-2507-4bit
```

## Settings

- `--max-tokens 8192`: default response limit, not context size
- `--prompt-cache-size 2`: retains two useful prefixes without targeting concurrent clients
- `--prompt-cache-bytes 3000000000`: accommodates two 8k caches or one 16k cache with headroom
- `--decode-concurrency 1`: prioritizes one agent's latency
- `--prompt-concurrency 1`: limits prefill memory use
- `--prefill-step-size 1024`: lowest measured TTFT at 2k, 8k, and 16k
- `--host 127.0.0.1`: keeps the development server local

`--prompt-cache-bytes` is not a hard process-memory limit or OOM guard.

## Model Cache Size

The model has 36 full-attention layers, 8 KV heads, a 128-element head dimension, and a 16-bit KV cache. One sequence grows by approximately 144 KiB per cached token:

| Tokens | Approximate cache |
| ---: | ---: |
| 8,192 | 1.13 GiB |
| 16,384 | 2.25 GiB |
| 32,768 | 4.50 GiB |

This excludes 2.11 GiB of model weights, activations, prefill temporaries, allocator overhead, and macOS memory. The model advertises a 262k context, but that is not practical on this 16 GB machine.

## Adjustments

- Prefer prompts at or below 16k tokens.
- Avoid 32k prompts: one measured cold request took about 401 seconds to first token and caused material swap growth.
- Keep both concurrency settings at `1` on this machine.
- Do not increase the cache budget without monitoring swap and memory pressure.

## Operating Tips

- Use AC power for sustained work.
- Expect performance to fall during repeated long prompts because the MacBook Air is fanless.
- Close memory-heavy applications before prompts near 16k.
- Check pressure with `memory_pressure -Q`.
- Do not change the wired-memory limit for this model.

See [M2 16GB Benchmarks](./m2-16gb-benchmark.md) for measured TTFT, decode speed, cache reuse, and memory behavior.
