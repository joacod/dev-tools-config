# MacBook Pro M4 Max 48GB

## Recommended Starting Point

For a 48 GB Mac, the optimal default is:

```
--prompt-cache-bytes 20000000000
```

20 GB of KV cache memory provides ~12–16k effective context while leaving plenty of headroom for model weights and system overhead.

## Full Command

```sh
mlx_lm.server \
  --model mlx-community/Qwen3.6-35B-A3B-4bit-DWQ \
  --port 8080 \
  --max-tokens 8192 \
  --prompt-cache-size 16 \
  --prompt-cache-bytes 20000000000 \
   --decode-concurrency 2 \
   --prompt-concurrency 1
```

Or using the launcher:

```sh
run-mlx-server --m4-48gb --model mlx-community/Qwen3.6-35B-A3B-4bit-DWQ
```

## Parameters

- `--max-tokens 8192` — caps response length (default 512 is too low for coding/agent use)
- `--prompt-cache-size 16` — number of prompt cache files
- `--prompt-cache-bytes 20000000000` — 20 GB KV cache, optimal for 48 GB hardware
- `--decode-concurrency 2` — decode concurrency (safer starting point; bump to 4 if stable under heavy tool-calling loads)
- `--prompt-concurrency 1` — prompt concurrency (safer starting point; bump to 2 if stable under heavy tool-calling loads)
- `--port 8080` — local server port
- `--model` — Hugging Face repo or local model path
