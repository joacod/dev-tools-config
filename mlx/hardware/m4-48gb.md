# MacBook Pro M4 Max 48GB

## Recommended Starting Point

For a 48 GB Mac, the optimal default is:

```
--prompt-cache-bytes 20000000000
```

20 GB of KV cache memory provides ~12–16k effective context while leaving plenty of headroom for model weights and system overhead.

## Full Command

```sh
mlx_lm.server \
  --model mlx-community/Qwen3.6-35B-A3B-4bit \
  --port 8080 \
  --prompt-cache-bytes 20000000000
```

Or using the launcher:

```sh
run-mlx-server --m4-48gb --model mlx-community/Qwen3.6-35B-A3B-4bit
```

## Parameters

- `--prompt-cache-bytes 20000000000` — 20 GB KV cache, optimal for 48 GB hardware
- `--port 8080` — local server port
- `--model` — Hugging Face repo or local model path
