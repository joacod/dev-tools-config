# MacBook Pro M4 Max 48GB

## Recommended Starting Point

For a 48 GB Mac, the conservative default is:

```
--max-kv-size 8192
```

This setting balances context length and memory usage, leaving room for the model weights and system overhead.

## Full Command

```sh
mlx_lm.server \
  --model mlx-community/Qwen3.6-35B-A3B-4bit \
  --port 8080 \
  --max-kv-size 8192
```

Or using the launcher:

```sh
run-mlx-server --m4-48gb --model mlx-community/Qwen3.6-35B-A3B-4bit
```

## Parameters

- `--max-kv-size 8192` — conservative long-context setting
- `--port 8080` — local server port
- `--model` — Hugging Face repo or local model path
